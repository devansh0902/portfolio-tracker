# Portfolio Management System - Frontend

This directory contains the user interface for the Portfolio Management System.

## Architecture Highlights
- Built extensively with **React 19** and **Vite** for optimized compiling and stateful speed.
- Routing managed gracefully via **React Router DOM v7**.
- Fully custom Vanilla CSS implementations (`index.css` & `App.css`) centered around high-end **Glassmorphism**, curated variables, and interactive hover mechanics without relying on generic external styling frameworks.
- Real-time interaction icons powered cleanly by **Lucide React**.
